## 洛琪希桌宠 v0.1.0

- Windows x64 安装包，内含 Electron；安装后无需 Node.js 或 pnpm。
- 界面和对话支持中文、日文、英文切换。
- 非官方《无职转生》粉丝创作试验，与原作权利方无关。
- 安装包尚未进行代码签名。Windows 可能显示安全提醒；请仅从本仓库下载，并可用附带的 SHA-256 文件核对。

## Roxy Desktop Pet v0.1.0

- Windows x64 installer with Electron included; no Node.js or pnpm required after installation.
- Chinese, Japanese, and English interface and dialogue options.
- Unofficial *Mushoku Tensei* fan experiment, unaffiliated with the original rights holders.
- The installer is unsigned. Windows may show a security warning; download only from this repository and verify the included SHA-256 checksum.
