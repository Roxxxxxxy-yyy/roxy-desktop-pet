# ロキシー・デスクトップペット · Codex 制作実験

Codex を使って制作した Windows 向けデスクトップペットの実験です。画面表示と会話のテキストは中国語・日本語・英語から選べます。キャラクターにマウスを重ねると表示されるメニューで切り替えられます。

『無職転生』のロキシーを題材にした非公式ファン作品です。原作の権利者とは関係ありません。キャラクター画像はこのプロトタイプの表示用です。公式素材として扱ったり、画像だけを転売したりしないでください。

## 機能

- 透明で常に手前に表示されるウィンドウ。ドラッグで移動できます
- 6 種類の表情とポーズ、ランダムな小移動・アクション・会話
- クリックに反応し、会話テキストも選択言語に合わせて切り替わります
- 70%～140% のサイズ調整、非表示・終了・トレイ操作
- 言語とサイズの設定をローカルに保存

## ダウンロードとインストール

[Releases](https://github.com/Roxxxxxxy-yyy/roxy-desktop-pet/releases) から `RoxyDesktopPet-Setup-*-x64.exe` をダウンロードして実行してください。インストーラーには Electron が含まれ、インストール後の利用に Node.js や pnpm は不要です。このビルドにはコード署名がないため、Windows の警告が表示される場合があります。ダウンロード元は本リポジトリの Releases に限定してください。

## ソースからの起動・ビルド

Windows、Node.js、pnpm が必要です。プロジェクトのフォルダーで次を実行してください。

```powershell
pnpm install
pnpm start
```

インストール後は `启动桌宠.cmd` をダブルクリックして起動することもできます。

Windows でインストーラーを作るには `pnpm run build:win` を実行してください。出力先は `dist/` です。
